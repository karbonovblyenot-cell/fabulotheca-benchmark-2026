# Приложение к статье «Поисковый сервис «Фабулотека» для сказковедения: устройство и сравнение с аналогами»

Данные сравнения поискового сервиса «Фабулотека» (https://fabulotheca.org) с научным поисковиком Consensus (https://consensus.app) и каталогом Folklore Database (https://folkloredatabase.com) на материале русского сказковедения и фольклора народов России. Октябрь 2026 г.

## Набор запросов
`queries_52.jsonl` — 52 запроса шести групп: P — персонажи и образы русской сказки (13); S — собиратели и сказители (12); U — шифры сюжетных типов (10); E — англоязычные запросы (10); N — фольклор народов России (5); R — Русский Север (2).

## Критерий оценки (единый для всех систем)
- «+» — работа посвящена сюжету, персонажу, собирателю или изданию, указанному в запросе, либо выданная строка взята из текста сказки, полевой записи или указателя сюжетов;
- «~» — тема рассматривается внутри более широкой работы (антология, обзор, применение метода);
- «−» — упоминание в перечне или списке литературы, пример мимоходом, посторонний материал.

Две меры: «строго» — число мест с оценкой «+»; «по теме» — «+» и «~». Учитываются первые 10 различных источников выдачи. Для Consensus, выдающего только заглавие и аннотацию, оценивалась работа в целом.

## Состав
- `fabulotheca/lists.md` — выдача Фабулотеки по всем 52 запросам (10.10.2026): автор, заглавие, год и строка совпадения для первых 10 источников.
- `fabulotheca/scores_by_query.md` — оценки по запросам.
- `consensus/lists.md` — выдача Consensus (веб-приложение, 6–9.10.2026): по 20 работ на запрос, только библиографические данные (без автоматических пересказов сервиса). Обозначения: U — шифры, SW01–SW09 — собиратели (Ончуков, Афанасьев, Садовников, Зеленин, Худяков, Карнаухова, братья Соколовы, Пропп, Азадовский), N — народы России, R — Русский Север, E — англоязычные запросы.
- `consensus/scores_P_E_S.md` — поштучные оценки Consensus по группам P и E и по запросам «сказочник Свиньин», «сказочница Винокурова», «сказочник Господарев» (6.10.2026; для групп P и S — через подключение к ассистенту).
- `consensus/scores_U_S_N_R.md` — оценки Consensus по группам U, S (собиратели), N, R.
- `folklore_database/counters.md` — счетчики экрана результатов Folklore Database по 14 запросам, введенным вручную 10.10.2026. Тексты выдачи каталога не воспроизводятся: условия сайта запрещают их автоматическое получение и использование.
